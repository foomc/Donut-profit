# foomc's Profit Mod (Fabric 1.21.11)
YouTube: https://www.youtube.com/@FooMc2/videos

Rainbow "Profit of the Day" HUD. Reads your balance from the sidebar scoreboard; profit = current balance minus balance when you first joined this game session. In-memory only, so it resets when the game closes.

Build: `gradle build` (or `./gradlew build` if you add the wrapper) -> `build/libs/donut-profit-1.0.0.jar`
Commands: `/profit reset`, `/profit toggle`
